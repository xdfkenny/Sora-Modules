# Product

## Register

product

## Users

Sora / Luna / Shirox mobile-app users (anime, movie, manga and novel streamers) who browse this site to find, verify and one-tap-install scraper modules into their player app. Many arrive from search on a phone; some are developers checking the harness or repo. They are in a task: find a source for their content, confirm it works and is maintained, install it.

## Product Purpose

A curated library of JavaScript scraper modules for the Sora family of streaming apps. The site showcases each module (icon, language, content type, supported apps, last-updated), filters them by category / app / search, links installs via `sora://` deep links, and surfaces verified third-party ("Cufiy") modules as external links. Success = a visitor finds a working module and installs it in under a minute.

## Brand Personality

"Soft Cryo": icy pastel, pure frost with a warm heart. Friendly, frosty, trustworthy. Zero sharp corners, calm motion. Voice is plain and specific (install in one tap; verified before it ships), never marketing-speak.

## Anti-references

- Generic AI-slop landing pages: gradient text, glassmorphism cards, hero-metric grids, eyebrow on every section.
- Dense developer dashboards: this is a consumer install page, not an admin panel.
- Aggressive dark "hacker" aesthetics; the brand is pastel frost in both themes.

## Design Principles

- Task first: the install button is always visible and legible; the tool disappears into the task.
- Earned familiarity: standard pills, cards, search patterns; no invented affordances.
- Reality reflected: cards hydrate from live manifests so versions, languages and update dates are true.
- Same vocabulary everywhere: one card format for owned and Cufiy modules; one button shape per action.
- Calm frost: motion conveys state only (loading, copy feedback, filter changes), 150–300ms.

## Accessibility & Inclusion

Target WCAG 2.1 AA. Full keyboard support on filters and cards, visible focus rings, `aria-pressed` filter state, `aria-live` result count and toast, reduced-motion fallbacks for snow/hex/card animations, AA-safe `--accent-ink` for accent text on light surfaces, dark theme with verified contrast.
