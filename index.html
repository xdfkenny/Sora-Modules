xdfkenny's Sora Modules Library

xdfkenny's sora module library is a curated collection of sora modules for streaming anime, movies, manga and novels in Sora, Luna and Shirox. Install the whole sora modules library with one tap, or pick individual modules from the grid.

What are sora modules? expand_more

Sora modules are lightweight JavaScript scrapers that plug streaming sources (anime, movies, manga, novels) into the Sora app (and Luna / Shirox). Every module in this sora module library is written and maintained by xdfkenny and verified before it ships.

How do I install sora modules? expand_more

One tap: use the "Add All to Sora" button (or the Add button on any card), which opens a sora:// deep link that installs the xdfkenny sora modules library straight into the app. No copy-pasting manifest URLs.

Is the xdfkenny sora module library free? expand_more

Yes. The sora modules library is completely free to browse and install. Optional donations help keep the xdfkenny sora module collection verified and alive.
